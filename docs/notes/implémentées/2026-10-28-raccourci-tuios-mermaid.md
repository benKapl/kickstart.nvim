# Raccourci `<leader>tM` : diagrammes Mermaid dans un pane tuios

**Décision** : dans un fichier Markdown, `<leader>tM` lance `tuios mermaid --watch <fichier>` dans un nouveau pane
tuios (sans prendre le focus). Rendu texte (caractères de boîte), redessiné à chaque enregistrement.

**Pourquoi** : voir les diagrammes sans navigateur ni plugin ; render-markdown laisse les blocs mermaid en source.
